# CSS 训练场

欢迎来到 CSS 训练场

这个分支为`rsbuild`，不再使用`webpack`，配置文件的内容大大缩减！！！🤣

### 目的

1. 巩固学习的 css 知识
2. 实现一些实用，有趣，绚烂的 css 效果/布局/场景
3. 使用非 Vue/React 等框架，通过 构建工具 和 monorepo 来做场地，巩固这方面的知识
